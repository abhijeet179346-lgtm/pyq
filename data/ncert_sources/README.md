# NCERT resources

This Drive folder is organized into four subjects: Physics, Chemistry, Mathematics, and Biology. Each subject folder links to NCERT's official textbook portal. Choose the class and language there to see available books and chapters.

- [Official NCERT textbooks (Classes I–XII)](https://ncert.nic.in/textbook.php)
- [ePathshala](https://epathshala.nic.in/epathshala.php?id=Students&ln=en)

NCERT permits textbook downloads for use or reference and prohibits republishing or redistribution. The folder therefore links to the official downloads rather than rehosting textbook PDFs.
